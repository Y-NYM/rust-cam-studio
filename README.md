## Исправления и обновления

- Android 0.6.1 исправляет перевёрнутое превью фронтальной камеры: убрано
  повторное преобразование поворота и зеркальности поверх матрицы Android.
- Исправлены ORIGINAL, нулевая сила эффекта, неполное применение аксессуаров,
  сохранение настроек рамки/аксессуара и повторная загрузка текстур при настройке.
- Доработаны Prism и Star. В Android добавлены замер перед вспышкой, экранная
  подсветка, тайм-аут снимка и защита при переключении камер.
- Начиная с Android/desktop 0.6.0 приложение проверяет GitHub Releases при
  запуске и работе в сети. «Обновить» запускает скачивание, «Позже» откладывает
  предложение на сутки. Скачанный файл проверяется по размеру и SHA-256;
  у APK также проверяются пакет, версия и ключ подписи.
- Android продолжает начатую загрузку через системный DownloadManager и
  открывает системный установщик. Windows/macOS скачивают проверенный ZIP;
  после загрузки закройте приложение и установите новую сборку из архива.

Версии 0.4.1/0.5.1 не содержат этого механизма: один раз установите новую
сборку вручную. Установка APK тем же ключом поверх прежнего сохраняет данные.

## Возможности

- Встроенная или USB-камера: живое превью эффекта, выбор устройства, съёмка по Enter.
- Переключатель отражения по горизонтали; одинаковая ориентация превью и снимка.
- Импорт JPEG/PNG и перетаскивание фотографии в окно.
- Каталог камер и плёнок, рамки, EV, баланс белого, зерно и насыщенность.
- Кадрирование и приближение; фото внутри окна Inst-рамки.
- Двойная экспозиция из двух фотографий.
- Экспорт JPEG/PNG, выбор папки сохранения и история файлов.
- Локальная обработка: фотографии не отправляются на сервер.

## Запуск

### Windows

1. Распакуйте Windows ZIP целиком.
2. Откройте `RustCamStudio.exe`.
3. Для установки ярлыка на рабочий стол нажмите правой кнопкой по `Install.ps1`
   и выберите «Выполнить с помощью PowerShell». Можно продолжать пользоваться EXE без установки.
4. Нажмите «Камера» и выберите устройство справа. «Сделать снимок» или Enter
   фиксирует кадр и сохраняет JPEG. «Снимать ещё» возвращает прямой эфир.

Установка выполняется в `%LOCALAPPDATA%/Programs/RustCamStudio` без прав
администратора. Ярлык запускает камеру сразу. По умолчанию снимки попадают
в системную папку «Изображения / Rust Cam»; папка меняется справа в приложении.
Для работы камеры нужен доступ к камере для классических приложений Windows.

### macOS

1. Распакуйте macOS ZIP и перенесите `Rust Cam Studio.app` в Applications.
2. Откройте приложение и разрешите доступ к камере, если хотите снимать.

Сборка содержит обе архитектуры. Она имеет локальную ad-hoc подпись,
не имеет Developer ID и нотариализации Apple. На настоящем Mac запуск
и доступ к камере пока не проверены; Gatekeeper может ограничить запуск.

## Сборка из исходников

Нужны Rust/Cargo и системные инструменты сборки соответствующей платформы.

Windows (PowerShell; MSVC с Visual Studio Build Tools или настроенный MinGW):

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
```

Готовый EXE: `dist/windows/RustCamStudio.exe`. Для Windows-иконки и сведений
о версии в GNU-сборке скрипт использует `windres`, если он найден.

macOS (Xcode Command Line Tools, Rust):

```bash
bash build-macos.sh
```

Результат: Universal2 `.app` и ZIP в `dist/macos`.

Проверки:

```bash
cargo test -p dazz-core -p dazzcam --lib --locked
```

Дополнительная проверка физической камеры запускается отдельно, при
подключённой камере и предоставленном системном доступе:

```bash
cargo test -p dazzcam --lib physical_webcam_stream_and_restart -- --ignored
```

Пример экспорта без интерфейса:

```powershell
.\RustCamStudio.exe --render input.jpg --output result.png --camera instsqc
```

Android-код также включён. Инструкции — в [README-RU.md](README-RU.md).
Для APK нужен собственный ключ, который хранится локально в `signing/`.
Пароли задаются переменными окружения `RUSTCAM_KEYSTORE_PASSWORD` и
`RUSTCAM_KEY_PASSWORD`, псевдоним — `RUSTCAM_KEY_ALIAS`. Приватного ключа
и паролей в репозитории нет. Сохраните прежний ключ для обновления уже
установленного APK: новый ключ не позволит установить обновление поверх него.
JDK 21 выбирается через `JAVA_HOME`; версии Android SDK/NDK указаны в скрипте.

## Состояние версии

В версии 0.6.0 прошли 30 модульных тестов, 936 сочетаний профиля/аксессуара/силы
эффекта и 156 вариантов Android GPU-рендера для 52 профилей. На Windows проверены
настоящий GUI и экспорт JPEG/PNG. Физическая HP Wide Vision HD Camera 1280×720
проверялась ранее в 0.5.1: остановка, повторный запуск и сохранение снимка.

Android 0.6.1 проверен в эмуляторе: ориентация превью относительно JPEG обеих
камер в квадратном, портретном и видеоформате; фото, MP4, скачивание из GitHub,
напоминание и открытие установщика. Вспышка на физическом телефоне не проверена.
macOS проверен по двум архитектурам, структуре и ad-hoc подписи; на настоящем
Mac приложение пока не запускалось. Доступность каждого устройства не гарантируется.

Настольная версия работает с фотографиями и кадрами камеры. Запись видео
остаётся функцией Android. Рецепты эффектов приближённые; точное совпадение
с Dazz Cam не заявляется.
